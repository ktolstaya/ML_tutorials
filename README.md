# Нейронные сети для инженеров — блокноты Jupyter к лабораторным работам и дополнительные примеры

Цифровые материалы к учебному пособию «Нейронные сети для инженеров»: иллюстрации лабораторных работ на Python и дополнительные примеры, которые не входят в основной текст глав.

Основная вычислительная среда пособия — российская платформа Engee (Julia). Блокноты Jupyter из этого репозитория воспроизводят лабораторные работы на Python и дополняют их. Сами лабораторные работы и их Engee-скрипты описаны в тексте глав и здесь не меняются.

## Общие соглашения

**Лабораторные работы и дополнительные примеры устроены по-разному.**

- *Лабораторные работы* (`lab03`, `lab04`) повторяют порядок выполнения из глав и используют **общие данные** в формате CSV. Эти данные одинаковы для Engee, MATLAB и Python, поэтому результаты разных сред можно сравнивать с контрольными значениями в тексте главы. Если файлов данных нет, блокнот создаёт их сам. Результаты и рисунки сохраняются для отчёта.
- *Дополнительные примеры* **полностью независимы**. Они не читают и не записывают файлов: все данные моделируются при каждом запуске, рисунки и таблицы выводятся только на экран. Единственная внешняя зависимость примеров главы 4 — модуль `kan.py`.

**Оформление единое для всех блокнотов.**

- Рисунки векторные (SVG), чёрно-белые с серошкальными заливками. Шрифт STIX совместим по начертанию с Times New Roman.
- Классы данных и кривые различаются формой маркеров и типом линий, а не цветом.
- Десятичный разделитель на осях и в таблицах — запятая.
- Каждое обозначение вводится при первом использовании. Номера формул совпадают с текстом глав, например (3.37), (4.32).
- Соглашение главы 2: входной слой только передаёт данные и не считается вычислительным. Запись 21–21–15–3 означает 21 вход, два скрытых слоя из 21 и 15 нейронов и 3 выхода.
- Расчётные ядра написаны на NumPy с явными градиентами, без специализированных нейросетевых библиотек. Ручные реализации проверяются конечными разностями.

**Требования.** Python 3.10 или новее, NumPy, pandas, Matplotlib. Для `lab03_approximation.ipynb` дополнительно нужен SciPy (только в дополнительном задании, шаг 9).

## Глава 3. Аппроксимация функций

**Задача.** По 21 отсчёту гауссова импульса y = C·exp(−(x − A)²/S) восстановить его параметры C, A, S. Нейронная сеть 21–21–15–3 аппроксимирует обратное отображение «отсчёты → параметры». Её сравнивают с аналитическим восстановлением через логарифм и с нелинейным МНК. Порядок шагов соответствует п. 3.4.7.

### `ch03_Lorenz_SINDy.ipynb` — дополнительный пример «Аттрактор Лоренца, часть 1»

**Задача.** Восстановить уравнения системы Лоренца по записи траектории методом SINDy (Sparse Identification of Nonlinear Dynamics). Это МНК в библиотеке мономов с пороговым отсечением малых коэффициентов. Пример иллюстрирует формулы (3.5)–(3.7), квадратурные формулы примера 3.1 и вопросы экстраполяции из п. 3.1.1.

| Шаг | Содержание |
|---|---|
| 0 | Обозначения; функции моделирования, оценки производных, библиотеки, SINDy и метрик |
| 1 | Система Лоренца, три записи траектории, показатель Ляпунова (метод Бенеттина) |
| 2 | SINDy как МНК (3.5)–(3.6); нормировка столбцов и число обусловленности |
| 3 | Разреженность: МНК, гребневая регрессия (3.7) и пороговая регрессия STLSQ; выбор порога по валидации (фронт Парето) |
| 4 | Производные по данным: центральные разности, фильтр Савицкого–Голея как локальный МНК, интегральная постановка с формулами трапеций и Симпсона |
| 5 | Шум измерений и размер библиотеки (полиномы до 2-й и до 3-й степени, по 5 реализаций шума) |
| 6 | Прогноз траектории; время достоверного прогноза в единицах времени Ляпунова |
| 7 | Долгосрочная статистика: отображение Лоренца и распределение координаты z |
| 8 | Ограничения библиотеки, переход к главе 4 |

В конце блокнота даны шесть заданий и таблица связей с главами 4–11.

**Основные выводы примера:**

- формула Симпсона точнее формулы трапеций примерно в 300 раз;
- размер библиотеки — это априорное знание: лишние мономы приводят к ложным членам уже при шуме 1 %;
- горизонт прогноза растёт только логарифмически с уменьшением ошибки коэффициентов;
- ошибка коэффициентов — плохая мера качества модели динамики.

## Глава 4. Функциональное разложение и сети Колмогорова–Арнольда

### `kan.py` — реализация сети Колмогорова–Арнольда

Общий модуль, который импортируют все блокноты главы 4. Формулы соответствуют тексту главы:

- `knots`, `bspline` — равномерная сетка узлов и B-сплайны, (4.11)–(4.15);
- `silu`, `dsilu` — базовая функция и её производная, (4.20), (4.25);
- `KANLayer`, `KAN` — слой и сеть (4.17)–(4.19), обратный проход (4.24)–(4.26), обновление сетки (4.27), продолжение функций за границы сетки;
- `Adam`, `train` — метод Adam и обучение по MSE (4.23) с отбором по валидации;
- `check_gradients` — проверка градиентов конечными разностями.

Функции `train` и `check_gradients` работают с любой моделью, у которой есть методы `forward`, `backward` и `params`, например с перцептроном из `lab04.ipynb`.

### `KAN_примеры.ipynb` — дополнительные примеры

1. **a·cos x + b — когда сеть сводится к МНК.** Сеть 1–1 сравнивается с прямым решением МНК. Обученная функция раскладывается на базовую и сплайновую части. Дальше идут символизация по библиотеке функций с таблицей R² и экстраполяция.
2. **exp(sin πx + y²) — когда нужны композиция и итеративное обучение.** Линейные модели сравниваются с KAN. Символизация проверяет структуру формулы. Отдельно разобраны поведение за пределами квадрата обучения и карты ошибок.

В конце дана итоговая таблица «что даёт сеть, а что — формула».

## Сквозной пример «Аттрактор Лоренца»

Одна и та же задача — восстановить уравнения системы Лоренца по наблюдениям — решается в нескольких главах. Методы различаются тем, сколько знания о модели закладывается заранее:

| Часть | Глава | Метод | Что известно заранее | Статус |
|---|---|---|---|---|
| 1 | 3 | SINDy | библиотека функций; ищутся коэффициенты | `ch03_Lorenz_SINDy.ipynb` |
| 2 | 4 | KAN | ничего; функции на связях обучаются, формула восстанавливается символизацией | `KAN_Lorenz_attarctor.ipynb` |
| 3 | 11 | PINN | вид уравнений; ищутся параметры σ, ρ, β по редким зашумлённым наблюдениям | планируется |

Во всех частях одинаковы параметры системы (σ = 10, ρ = 28, β = 8/3) и шаг записи Δt = 0,01. Наборы данных и сиды в каждом блокноте свои, потому что блокноты независимы.

Возможные продолжения:

- в главах 7–8 — прогноз временного ряда сетями LSTM и GRU без знания уравнений;
- в главе 10 — показатели Ляпунова, устойчивость и аттракторы как объект теории.
